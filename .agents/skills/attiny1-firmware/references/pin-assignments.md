# Pin assignments

## Scope

Applies to Microchip (Atmel) tinyAVR 1-series devices.

This document defines the priority source of truth about the post multiplexing on this series of devices. If a port/pin function assignment is not mentioned here, then the device datasheet will become the source of truth. But when reading the datasheet, be careful about misinterpretations due to legibility issues.

NOTE - THERE ARE DIFFERENT PINOUTS. FOR EXAMPLE THERE'S A 20-PIN SOIC AND A 24-PIN VQFN (AND MAYBE OTHERS) AND WE NEED TO DISTINGUISH BETWEEN THEM.

DIVIDE DEFAULT AND ALTERNATE PIN ASSIGNMENTS BY PERIPHERAL FUNCTION.
